## Change method

Version 1.1 is an additive successor to the approved-in-principle Version 1.0. Existing major sections 1–19 were preserved. Stage 2.5 was inserted as Section 8A so that the established numbering of Stages 3–6 remained unchanged. The approved Version 1.0 file was not rewritten.

No software, source code, placeholder modules, package structure, strategy, optimisation, broker integration, execution component, or live-trading component was introduced. MDM remains the sole authorised market-data source.

## Compatibility

Version 1.1 does not weaken any Version 1.0 boundary. The stricter additive controls govern: unvalidated features and unsatisfied dependencies block discovery; exploration limits cannot be reset through renamed work; Research Cost and ESIG cannot change evidence; negative and superseded evidence remains permanent; and phenomenon relationships require their own governed evidence.
